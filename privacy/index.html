# To.U 개인정보처리방침 **시행일: 2026년 12월 4일 (예정)** To.U(이하 '앱')는 박영서(이하 '개발자')가 제공하는 개인용 생일 및 위시리스트 관리 서비스입니다. 개발자는 이용자의 개인정보를 보호하고 관련 법령을 준수하기 위해 다음과 같이 개인정보처리방침을 안내합니다. ### 제1조. 개인정보의 처리 목적 To.U는 다음 목적을 위해 정보를 처리합니다. 1. 친구의 이름, 생일 및 프로필 관리 2. 친구별 위시리스트 및 상품 정보 관리 3. 상품 사진 분석을 통한 상품 정보 확인 4. 상품 링크 분석 및 상품 검색 5. 생일 및 일정 알림 제공 6. 서비스 오류 확인 및 안정적인 기능 제공 ### 제2조. 처리하는 정보의 항목 앱에서 이용자가 직접 입력하거나 선택하는 정보는 다음과 같습니다. - 친구의 이름, 생일, 프로필 사진 - 위시리스트의 상품명, 브랜드, 가격, 상품 링크 및 이미지 - 이용자가 입력한 메모와 선물 관리 정보 - 상품 분석을 위해 선택한 사진 및 상품 링크 - 알림 설정 정보 To.U는 별도의 회원가입 및 로그인 기능을 제공하지 않습니다. ### 제3조. 개인정보의 처리 및 저장 방법 친구 정보, 생일, 위시리스트 등 앱의 기본 관리 데이터는 이용자 기기의 IndexedDB에 저장됩니다. 해당 데이터는 별도의 회원 계정과 연결되지 않으며, 개발자가 운영하는 데이터베이스에 동기화하지 않습니다. 다만 상품 분석 및 검색 기능을 사용하는 경우, 기능 수행에 필요한 사진이나 상품 정보 등이 인터넷을 통해 외부 서비스로 전송될 수 있습니다. ### 제4조. 외부 서비스 및 정보 전송 To.U는 상품 분석과 검색 기능을 제공하기 위해 다음 서비스를 이용할 예정입니다. 1. **Google Gemini API:** 이용자가 선택한 상품 이미지 분석 2. **Groq API:** 상품 링크에서 확보한 상품명, 브랜드, 가격 등의 정보 분석 3. **NAVER Shopping API:** 상품 검색 및 상품 정보 조회 4. **Cloudflare Workers:** 외부 API 요청 중계 및 인증키 보호 각 서비스에는 해당 기능을 수행하는 데 필요한 정보만 전송하도록 설계합니다. 이용자가 상품 분석 기능을 실행하면 관련 정보가 외부 서비스 제공업체의 시스템에서 처리될 수 있습니다. 실제 전송 항목, 외부 서비스 제공업체의 정보 보관 여부, 국외 처리 및 위탁에 관한 세부사항은 서비스 연동 방식이 확정된 후 본 방침에 반영합니다. ### 제5조. 개인정보의 보유 및 삭제 앱 내부에 저장된 친구 정보 및 위시리스트 데이터는 이용자가 직접 삭제하거나 앱의 저장 데이터를 초기화할 때 삭제할 수 있습니다. 앱을 삭제하면 일반적으로 기기에 저장된 앱 데이터도 삭제되지만, 기기 또는 운영체제의 백업·복원 설정에 따라 달라질 수 있습니다. 외부 API 제공업체가 처리하는 정보의 보관 및 삭제 기준은 해당 제공업체의 정책과 실제 서비스 이용 조건에 따릅니다. ### 제6조. 앱 권한 사용 To.U는 다음 기능을 위해 기기 기능에 접근할 수 있습니다. - **사진 선택:** 상품 이미지 및 친구 프로필 사진 등록 - **알림:** 생일 및 일정 알림 제공 앱은 기능 제공에 필요한 범위에서만 접근 권한을 사용하며, 운영체제에서 허용하는 경우 이용자는 기기 설정을 통해 권한을 변경할 수 있습니다. ### 제7조. 개인정보 보호 조치 개발자는 이용자의 정보를 보호하기 위해 다음 조치를 적용할 예정입니다. - 외부 API 요청에 HTTPS 통신 사용 - Cloudflare Workers를 통한 API 인증키 보호 - 외부 서비스로 전송하는 데이터의 최소화 - 앱 기능에 불필요한 기기 접근 권한 제한 - 불필요한 서버 저장 및 요청 로그 최소화 ### 제8조. 이용자의 권리 이용자는 앱에서 등록한 친구 정보 및 위시리스트를 조회, 수정, 삭제할 수 있습니다. 개인정보 처리와 관련한 문의는 아래 이메일을 통해 접수할 수 있습니다. ### 제9조. 개인정보 보호 관련 문의 - **개발자:** 박영서 - **서비스명:** To.U - **이메일:** uiux.to.u@gmail.com ### 제10조. 개인정보처리방침 변경 본 방침의 내용이 변경되는 경우 앱 또는 개인정보처리방침 게시 페이지를 통해 변경 내용을 안내합니다. **시행 예정일: 2026년 12월 4일**
