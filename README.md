# 📁 Project Repository

이 저장소는 팀 프로젝트의 **기획, 디자인, 사용자 테스트, 팀 합의 및 개인별 활동 기록**을 관리하기 위한 공간입니다.

> 💡 실제 개발 코드는 별도의 Frontend / Backend Repository에서 관리합니다.
## 🗂️ 폴더 구조

```text
Project/
│
├── design/
│   ├── image/
│   └── design.md
│
├── docs/
│   ├── PRD.md
│   ├── 사용자_테스트.md
│   └── 합의서.md
│
├── members/
│   ├── 박수진/
│   │   ├── contribution.md
│   │   └── retrospective.md
│   │
│   ├── 박영서/
│   │   ├── contribution.md
│   │   └── retrospective.md
│   │
│   └── 오시언/
│       ├── contribution.md
│       └── retrospective.md
│
└── wireframes/
    ├── 박수진/
    ├── 박영서/
    └── 오시언/
```

## 🎨 `design/`

팀에서 최종적으로 결정한 **디자인 결과물**을 관리합니다.

| 파일 / 폴더 | 내용 |
| --- | --- |
| `design.md` | 최종 Figma 링크 및 디자인 관련 설명 |
| `image/` | 최종 디자인 이미지 및 필요한 시각 자료 |

> Figma에서 실제 디자인 작업을 진행하고, 최종 Figma 링크와 관련 정보를 `design.md`에 기록합니다.

## 📄 `docs/`

프로젝트를 진행하면서 팀 전체가 공유해야 하는 **기획 및 프로젝트 문서**를 관리합니다.

| 파일 | 내용 |
| --- | --- |
| `PRD.md` | 서비스 목표, 타겟 사용자, 핵심 기능 등 제품 요구사항 |
| `사용자_테스트.md` | 사용자 테스트 방법, 결과, 발견한 문제 및 개선 사항 |
| `합의서.md` | 계정, 비용, 수익, 저작권 등 팀 내부 합의 사항 |

---

## 👥 `members/`

각 팀원의 **개인 기여 내용과 프로젝트 회고**를 기록합니다.

각 팀원은 자신의 이름으로 된 폴더를 사용합니다.

### `contribution.md`

프로젝트에서 본인이 담당하거나 기여한 내용을 기록합니다.

### `retrospective.md`

프로젝트를 진행하면서 경험한 과정과 배운 점을 기록합니다.

## ✏️ `wireframes/`

팀원별 **로파이 와이어프레임 및 초기 아이디어**를 보관합니다.

```text
wireframes/
├── 박수진/
├── 박영서/
└── 오시언/
```

각 팀원이 개별적으로 와이어프레임을 제작한 후 자신의 폴더에 결과물을 기록합니다. 최종 디자인은 팀 논의를 통해 결정하며, 확정된 결과는 `design/`에서 관리합니다.

## 📌 관리 원칙

1. 프로젝트 전체에 관한 문서는 `docs/`에서 관리합니다.
2. 최종 디자인 관련 자료는 `design/`에서 관리합니다.
3. 개인 작업 기록은 각자의 `members/이름/` 폴더에 작성합니다.
4. 개인 와이어프레임은 `wireframes/이름/`에 보관합니다.
5. 실제 개발 코드는 Frontend / Backend Repository에서 별도로 관리합니다.
6. 팀에서 합의된 최종 자료만 `main` 브랜치에 반영합니다.
